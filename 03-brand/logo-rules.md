# Purpose

This document defines the official rules for using the Maroc Local Hub logo.

The logo is one of the platform's most valuable assets and must always be displayed consistently.

---

# Brand Values

The logo represents:

- Authenticity
- Trust
- Innovation
- Moroccan Heritage
- Technology
- Global Commerce

---

# Logo Versions

The official logo includes:

- Primary Logo
- Secondary Logo
- Icon Only
- Monochrome Version
- White Version

---

# Minimum Size

Digital:

Minimum width: 32 px

Print:

Minimum width: 15 mm

---

# Clear Space

Always leave empty space around the logo.

Minimum clear space equals the height of the letter "M" in the logo.

No text or graphics may enter this area.

---

# Approved Backgrounds

The logo may appear on:

- White
- Black
- Brand Green
- Light Gray
- Transparent

---

# Incorrect Usage

Never:

- Stretch the logo
- Rotate it
- Change colors
- Add shadows
- Add outlines
- Compress proportions
- Change typography
- Place on busy backgrounds
- Reduce readability

---

# Logo Placement

Preferred positions:

- Top Left
- Top Center
- Website Header
- Mobile Splash Screen
- Product Packaging
- Social Media Profile

---

# File Formats

Official formats:

- SVG
- PNG
- PDF
- EPS
