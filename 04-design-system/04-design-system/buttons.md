# Purpose

This document defines the button system used across Maroc Local Hub.

Buttons must be consistent, accessible, and easy to use.

---

# Button Types

Primary

Main platform action.

Secondary

Alternative action.

Outline

Less important action.

Ghost

Minimal action.

Danger

Delete or destructive action.

Success

Confirmation action.
