# Purpose

This document defines the icon system used throughout Maroc Local Hub.

Icons should be simple, recognizable, and consistent across the platform.

---

# Icon Style

- Outline icons
- Rounded corners
- Minimal design
- Consistent stroke width
- Modern appearance

---

# Recommended Libraries

- Lucide Icons
- Heroicons
- Material Symbols

# Usage Rules

- One meaning per icon
- Maintain consistent sizing
- Do not stretch icons
- Keep enough spacing around icons
- Always align icons with text

---

# Accessibility

- Decorative icons should be hidden from screen readers.
- Functional icons must include accessible labels.
- Icons must always have sufficient contrast.
