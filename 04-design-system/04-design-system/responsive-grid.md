# Purpose

This document defines the responsive grid system for Maroc Local Hub.

The layout must adapt smoothly across mobile, tablet, laptop, and desktop devices.

---

# Breakpoints

Mobile

0–767px

Tablet

768–1023px

Laptop

1024–1279px

Desktop

1280px+

# Layout Rules

- Mobile First
- Flexible containers
- Responsive images
- Consistent spacing
- RTL and LTR support

---

# Accessibility

- Maintain readable layouts on all screen sizes.
- Avoid horizontal scrolling.
- Ensure touch-friendly spacing.
- Follow WCAG AA guidelines.
