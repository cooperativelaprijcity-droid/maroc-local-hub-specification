# Accessibility

All color combinations must comply with WCAG AA standards.

Never rely on color alone to communicate meaning.

Always provide icons or labels where necessary.

---

# RTL Support

The color system must remain identical for both RTL and LTR interfaces.

Colors must never change depending on language direction.

---

# Conclusion

The color system is one of the foundations of the Maroc Local Hub Design System and must be used consistently across the website, mobile application, admin dashboard, and future products.
