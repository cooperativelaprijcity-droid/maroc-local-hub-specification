# Icon System

Document ID: MLH-UI-003
Version: 1.0.0
Status: Draft
Owner: Maroc Local Hub

## Purpose

This document defines the icon system used across Maroc Local Hub.

Icons should improve usability, communicate meaning quickly, and remain consistent across the platform.

---

# Design Principles

Icons must be:

- Simple
- Modern
- Minimal
- Consistent
- Recognizable
- Mobile-first

---

# Icon Sizes

Recommended sizes:

- 16px
- 20px
- 24px
- 32px
- 48px
- 64px

---

# Icon Categories

The platform should support icons for:

- Home
- Search
- User
- Seller
- Store
- Product
- Shopping Cart
- Wishlist
- Orders
- Payment
- Shipping
- Location
- Notifications
- Chat
- Settings
- Help
- Camera
- Gallery
- Upload
- Download
- Edit
- Delete
- Share
- Favorite
- Filter
- Menu
- Close
- Arrow
- Back
- Forward

---

# Accessibility

Icons must:

- Support screen readers
- Include accessible labels
- Have sufficient contrast
- Be easy to recognize

---

# RTL Support

Icons must support Arabic RTL layouts.

Directional icons should automatically flip when appropriate.

---

# Design Guidelines

Avoid unnecessary decorative icons.

Icons should communicate meaning instantly.

Use the same icon style throughout the platform.

---

# Mobile Experience

Icons should remain clear on small screens.

Minimum touch target:

44px

---

# Conclusion

A consistent icon system improves navigation, usability, and user experience across Maroc Local Hub.
