# Shopping Cart Page

Document ID: MLH-PAGE-005

Version: 1.0.0

Status: Draft

Owner: Maroc Local Hub

## Purpose

This document defines the Shopping Cart Page.

The Shopping Cart allows users to review selected products before checkout.

---

## Main Sections

- Cart Items
- Product Image
- Product Name
- Seller
- Quantity Selector
- Price
- Remove Item
- Order Summary
- Discount Code
- Checkout Button

---

## User Actions

Users should be able to:

- Update Quantity
- Remove Products
- Apply Coupon
- Continue Shopping
- Proceed to Checkout

---

## Mobile Experience

The page must be optimized for smartphones.

---

## Accessibility

Support keyboard navigation and screen readers.

---

## RTL Support

Support Arabic RTL layouts.

---

## Conclusion

The Shopping Cart should provide a simple and fast shopping experience.
