# Category Page

Document ID: MLH-PAGE-003

Version: 1.0.0

Status: Draft

Owner: Maroc Local Hub

## Purpose

This document defines the Category Page used to display products belonging to a specific category.

---

## Main Sections

- Category Banner
- Category Title
- Breadcrumb Navigation
- Filters
- Sorting Options
- Product Grid
- Pagination

---

## Filters

Users should be able to filter by:

- Price
- Brand
- Seller
- Rating
- Availability
- Location

---

## Sorting

Supported sorting options:

- Newest
- Popular
- Best Rating
- Lowest Price
- Highest Price

---

## Mobile Experience

The page must be optimized for smartphones.

---

## Accessibility

The page must support keyboard navigation and screen readers.

---

## RTL Support

Support Arabic RTL layouts.

---

## Conclusion

The Category Page should help users quickly discover products through filtering and sorting.
