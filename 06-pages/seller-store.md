# Seller Store Page

Document ID: MLH-PAGE-004

Version: 1.0.0

Status: Draft

Owner: Maroc Local Hub

## Purpose

This document defines the Seller Store Page.

The page should showcase a seller's profile, products, ratings, and contact information.

---

## Main Sections

- Store Banner
- Store Logo
- Seller Information
- Seller Rating
- Store Description
- Product Categories
- Product Grid
- Customer Reviews
- Contact Seller

---

## User Actions

Users should be able to:

- Follow Store
- Contact Seller
- Browse Products
- Share Store

---

## Mobile Experience

The page must be fully responsive and mobile-first.

---

## Accessibility

Support keyboard navigation and screen readers.

---

## RTL Support

Support Arabic RTL layouts.

---

## Conclusion

The Seller Store Page should build trust and help customers discover products from a specific seller.
