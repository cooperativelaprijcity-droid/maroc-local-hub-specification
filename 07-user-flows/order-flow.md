# Purpose

This document defines the complete order lifecycle on Maroc Local Hub.

The order flow begins when the customer confirms the purchase and ends when the order is completed, cancelled, or refunded.

---

# Order Journey

Checkout
↓

Order Created
↓

Payment Confirmed
↓

Seller Notified
↓

Order Accepted
↓

Order Processing
↓

Order Shipped
↓

Order Delivered
↓

Customer Confirms Receipt
↓

Review Submitted

---

# Order Status

The platform shall support:

- Pending
- Awaiting Payment
- Payment Confirmed
- Accepted
- Processing
- Ready to Ship
- Shipped
- Out for Delivery
- Delivered
- Cancelled
- Refunded
- Returned

---

# Customer Actions

Customers can:

- View Order
- Track Shipment
- Download Invoice
- Contact Seller
- Cancel Eligible Orders
- Request Refund
- Leave Review

---

# Seller Actions

Sellers can:

- Accept Order
- Reject Order
- Update Order Status
- Print Shipping Label
- Add Tracking Number
- Communicate with Customer

---

# Notifications

The system shall notify users when:

- Order Created
- Payment Received
- Order Accepted
- Order Shipped
- Order Delivered
- Refund Approved

---

# Security

The system must:

- Protect order information
- Prevent unauthorized access
- Validate every status update
- Maintain an audit log

---

# Mobile Requirements

The order flow must be optimized for smartphones.

---

# Accessibility

Support keyboard navigation and screen readers.

---

# RTL Support

Support Arabic RTL layouts.

---

# Localization

Supported languages:

- Arabic
- French
- English
- Spanish

---

# Conclusion

The order flow should provide complete transparency and allow both buyers and sellers to manage orders efficiently.
